Doc to New Quiz

Upload an assignment document. Review the questions it finds and fix anything flagged, then download a file Canvas imports as a New Quiz or a question bank.

  1. 1Upload the .docx
  2. 2Review and fix
  3. 3Choose quiz or bank
  4. 4Import into Canvas

1Upload the assignment document

  • In Google Docs, accept or reject all suggestions and resolve comments first.
  • Then use File → Download → Microsoft Word (.docx).
  • Follow the authoring guide (Heading 2 for steps, Heading 4 for Directions, [*] after correct choices).
Other ways to add questions: spreadsheet, paste or example
Excel template CSV template Blank template Column guide Google Sheets setup
CSV, TSV, Excel or JSON. For Excel, the sheet named “Questions” is used (or the first sheet). A spreadsheet downloaded from step 1 can be edited and uploaded here.
Images from a Word document are added automatically. For a spreadsheet, add the image files its rows name in the image column or in <img src="…">.

    2Review and fix

    Each item shows what students will see. Click Edit on any item to change it, or From the document to compare it with the source.

    3Choose what to export

    Quiz settings

    Text blocks, the quiz instructions and quiz settings aren't part of a bank. Directions stay with the questions that use them. Not yet confirmed: where an imported bank shows up in your New Quizzes courses. Try it once in a sandbox course.

    Advanced

    Generic QTI 2.1 is only for ordering, categorization and hotspot questions, and Canvas's support for it is unconfirmed. It ignores quiz/bank choice, settings, stimulus links and images.

    4Import into Canvas

    Import the .zip

    1. In the course, open Settings and click Import Course Content.
    2. Content Type: QTI .zip file. Choose the downloaded zip.
    3. If you see Import existing quizzes as New Quizzes, make sure it's ticked.
    4. Choose All content and click Import. Wait for the job to show Completed.

    Then check the quiz

    • The quiz is under Quizzes, unpublished. Open it in Build.
    • Take it in Student View and answer a few questions to confirm scoring.
    • Images are in the course files under Uploaded Media.
    • Publish when it looks right.

    Then find the bank

    • In a New Quiz, open Build and the Item Banks panel to look for a bank with this title.
    • If your course still shows Classic tools, look under Quizzes → ⋮ → Manage Question Banks.
    • Add questions from the bank to a quiz, or set up a question group that draws from it.

    Import into a sandbox course first for new documents.

    Runs entirely in your browser. Your documents and questions aren't uploaded anywhere.
